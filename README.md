# Tic-Tac-Toe Game – Java

This is a command-line Tic-Tac-Toe game developed in Java as part of a university programming assignment.

## Project Description

The project focuses on applying object-oriented programming principles in Java. The game allows players to play Tic-Tac-Toe through the command line, while the code structure is designed to be clean, organized, and easy to maintain.

## Technologies Used

- Java
- Object-Oriented Programming
- Strategy Design Pattern
- Factory Design Pattern

## Main Features

- Command-line gameplay
- Player move handling
- Win and draw detection
- Organized game logic using object-oriented design
- Use of design patterns to improve code structure

## What I Learned

Through this project, I practiced Java programming, object-oriented design, code organization, and the implementation of design patterns in a practical application.
